# Books

Your reading list, by voice. Books you want to read, are reading and have read, with stars and notes.
Titles are found through [Open Library](https://openlibrary.org); your lists stay in the plugin's own
database inside your house.

## What it does

- `books` - what you are reading, and how long the to-read list is
- `books find <title or author>` - look it up
- `books want <title>`, `books start <title>`, `books done <title> [1-5]`, `books drop <title>`
- `books list [want|reading|read]`, `books show <title>`, `books note <title> <text>`
- `books year [YYYY]` - what you read in a year, with the pages

## Say to Iris

- "I want to read Project Hail Mary."
- "I finished The Hobbit, five stars."
- "What did I read this year?"

## Permissions

`internet`: only to search Open Library for a title. Your lists and notes never leave the house.
